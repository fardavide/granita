# Follow the Christmas calendar for the mobile icon

The Christmas alternate shows evergreen granita with a star, a candy cane straw, snow and the diff
marks on the glass.
Each color appearance keeps its lighter green at the edges so the icon's outline reads against
dark Home Screen wallpapers. A slight vertical gradient gives it a brighter top.
The schedule chooses it from December 1 through January 7 inclusive and the Granita glass for the
rest of the year. Use the Gregorian calendar in the device's current time zone, check each time
the app becomes active, and check significant time changes while the app is active.

The schedule is on by default. An existing Ice Cube icon came from a deliberate choice and starts
with the schedule off. Turning the schedule off keeps the current icon. Choosing a different icon
turns it off after the system confirms the change. Turning it on applies the schedule immediately.
Device defaults store the schedule and UIKit still owns the current icon, as in
[0233](0233-two-icons-and-only-the-phone-chooses.md). macOS ships the glass.
