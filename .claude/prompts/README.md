# Prompts

One file per ask that leaves this repository to be answered somewhere else — today that means
Claude Design, and each file is a fenced prompt ready to paste, opening with what it is for, who
wrote it and when, and against which doc.

A prompt is committed **before** the answer arrives and is not edited after it: it is the record of
what was asked, and a prompt quietly improved later makes the answer unreadable. Rules for writing
one, and for what to do with the reply, are in the
[`design-handoff`](../skills/design-handoff/SKILL.md) skill; returned frames are archived under
[`../docs/design/`](../docs/design/).

This is not where a hand-off to Davide lives. Something only he can do is a line in `status.md`
under what he still owns, and a sentence in the pull request that needs it.
